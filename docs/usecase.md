### UC-08 (청년 상세 조회)
**이해관계자 별 목표**  
- **ADMIN** : 청년 한명한명 모니터링 가능, 기관의 열람 기록 추적  
- **ORG** : 담당 청년의 현재 상태, 이력 파악  
- **청년** : 담당자에게만 정보 공유

**사전 조건**
- 로그인이 되어있어야함
- 대상 청년이 해당 기관에 배정되어야함

**사후 조건**
- 청년의 데이터가 반환됨
- 열람 기록이 로그에 저장됨

**기본 흐름**
1. ADMIN 또는 ORG 계정으로 청년 목록에서 청년 클릭
2. 시스템이 소속 기관 확인 (청년이 해당 기관에 소속되어있는지 검사)
3. 시스템이 청년 데이터 확인
4. 시스템이 열람 기록 작성
5. 시스템이 청년 데이터 반환

**분기 흐름**
- 2a. 검사 실패 시, 404 반환
- 4a. 로그 기록 실패 시, 실패 로그로 작성 (서비스는 계속 운영)

**특수 사항**
- 응답 시간 1초 이내 목표
- 로그 기록이 응답에 영향을 주지 않을 것
