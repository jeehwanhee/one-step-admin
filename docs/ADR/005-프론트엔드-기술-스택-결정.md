# ADR-005 프론트엔드 기술 스택 결정

- 상태 : accepted
- 날짜 : 2026-10-06

## 상황
프론트엔드를 어떤 것을 사용할지를 결정해야함

알아본 결과 react또는 vue를 선택하고 거기에 vite를 사용하는 것이 나아보임

## 선택지
**1. react**
대시보드 관련 컴포넌트 라이브러리가 많음
기본적인 문법을 알고있으며 특히 RN개발 경험이 있음
라우터, 상태관리 등 신경써야할 것이 더 많음

**2. vue**
템플릿이 HTML이랑 유사
공식 라우터, 상태관리가 정해져있음
컴포넌트 선택지가 적음


## 결정
선택지 1을 택한다.

언어 공부가 아니라 실제 프로젝트이기 때문에 사용해본 프레임워크를 사용하는 것이 좋다고 판단
또한 관리자 대시보드를 만들 때, 여러 컴포넌트를 비교하고 선택하기 위함

언어는 TypeScript로 작성하며 추가로 vite를 사용한다

## 결과
**얻는 것**
- 익숙한 프론트 환경
- 다양한 컴포넌트

**감수할 것**
- 더 많은 리소스 투입
- 결정할 것이 늘어남

**후속 작업**
- 컴포넌트 라이브러리 탐색 필요
