# ADR-003 데이터 감사 로그 비동기 적재

- 상태 : accepted
- 날짜 : 2026-10-05

## 상황
고립청년의 민감정보를 다루기 때문에 누가, 언제, 어떤 청년의 데이터를 열람했는지 기록할 필요가 있다.

하지만 감사 로그 기록이 API응답 시간에 영향을 주지않는 것이 목표

## 선택지
**1. 동기 적재**
감사 로그 누락이 없지만 응답 시간에 로그 기록이 포함됨
트랜잭션을 분리하지 않으면 사용자에게 로그 기록에 대한 에러가 반환될 수도 있음

**2. 비동기 적재**
응답 시간에 영향을 주지않고, 로그 쓰기를 실패해도 응답은 진행됨

## 결정
선택지 2을 택한다.

감사 로그 적재 실패 시에는 실패 정보만 별도의 로그로 기록


## 결과
**얻는 것**
- 응답 시간과 로그기록을 분리
- 로그 적재 실패가 노출되지 않음

**감수할 것**

**후속 작업**
- 로그가 계속 쌓이는 문제 해결, 정책 필요
- 감사 로그의 무결성을 보장하는 방법 공부 필요
