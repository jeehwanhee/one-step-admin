# ADR-002 타기관 접근 방지 정책

- 상태 : accepted
- 날짜 : 2026-10-05

## 상황
ORG 계정으로 본인 기관에 속하지 않은 청년의 정보를 요청한 경우의 응답을 결정해야한다

애초에 청년 목록에 해당 기관의 청년들만 나타나겠지만 추후 청년 검색 기능추가 등의 이유로 발생 가능성이 있는 상황이라고 판단하였다

## 선택지
**1. 403 forbidden**
의미는 정확하지만 해당 청년이 존재한다는 사실이 노출됨
-> 공격가능성이 존재

**2. 404 not found**
존재 여부와 소속이 다름을 구분하지 않음

## 결정
선택지 2을 택한다.

타 기관 리소스에 대한 접근은 존재하지 않는 것과 동일하게 취급하여 404를 반환한다

## 결과
**얻는 것**
- 다른 기관 정보를 추정할 수 없음

**감수할 것**
- 디버깅 시, 약간의 불편 존재 가능
