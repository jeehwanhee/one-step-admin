# one-step-admin

은둔, 고립 청년 지원 앱 [one-step](https://github.com/jeehwanhee/one-step)의 기관용 관리자 웹 서비스


---

## 프로젝트 목표

### 1. 기관이 청년의 비대면 활동을 추적할 수 있게 한다

담당자가 다음을 확인할 수 있어야 한다.

- 담당 청년별 마지막 접속 시점과 미접속 경과일
- 고립도 점수의 시간에 따른 변화
- 수행한 퀘스트와 검증 질문에 대한 답변
- 기타 앱에서 제공하는 청년 데이터

### 2. 민감정보를 다루는 시스템으로서 요구되는 수준을 충족한다

정신건강 관련 정보는 개인정보보호법상 민감정보에 해당한다. 기능이 아니라 **전제 조건**으로 다룬다.

- 기관 간 데이터 격리 — 타 기관 청년 정보에 접근 불가
- 역할 기반 접근 제어
- 검증 답변 등 민감 컬럼 암호화 저장
- 모든 열람 행위에 대한 로그 기록

### 3. 운영 중인 서비스의 데이터를 안전하게 이관한다

앱은 Firebase를 사용 중이며 출시 상태이므로, 서비스를 중단하지 않고 점진적으로 RDB로 옮긴다.

- 증분 동기화 배치
- 재실행에 대한 멱등성 보장
- 동기화 실패 시 데이터 유실 방지

### 4. 성능 요구를 충족한다

- 청년 목록 조회: 기관당 1,000명 기준 1초 이내
- 감사 로그 적재가 본 요청 응답 시간에 영향을 주지 않을 것
- 시계열 데이터 증가에 대응하는 인덱싱 및 집계 전략

### 5. AI 사용을 경계한다

해당 프로젝트에 한해서는 AI의 결과를 바로 사용하지 않고, 모든 코드나 문서를 직접 타이핑하는 것을 목표로 진행한다.

## 개발 기능 범위
기관 및 전문가의 자문을 구하기 전까지 아래의 범위에 맞춰 개발을 진행한다

### 포함

| 영역 | 내용 |
|---|---|
| 인증 | JWT 기반 로그인, 역할 분리 (ADMIN / ORG) |
| 멀티테넌시 | 기관별 데이터 격리 |
| 청년 조회 | 목록(필터·페이징), 상세, 퀘스트 이력, 고립도 추이 |
| 대시보드 | 기관별 요약, 전체 현황 |
| 데이터 동기화 | Firebase → MySQL 증분 배치 |
| 보안 | 컬럼 암호화, 감사 로그 |
| 기관 관리 | 기관 등록, 계정 생성, 청년 배정 |

### 제외

현장 요구사항 수집 이전까지 다음은 구현하지 않는다.

- 위기 알림 및 푸시 발송
- 기관에서 청년에게 맞춤 퀘스트 부여
- 실적 보고서 생성 및 내보내기
- 기관 자체 회원가입
- 앱 기능 변경
